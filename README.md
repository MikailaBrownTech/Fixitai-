# FixItFast

A secure, AI-driven appliance parts and repair search. A natural-language query
(for example, "heating element for whirlpool dryer WED4815EW") is parsed by an LLM
into structured entities, validated strictly, then used to query a public API.

Status: step 1 (repo and tooling). The full README, architecture diagram and
resume bullets come in step 11.

## Commands

```
npm install
npm test
npm run lint
npm run typecheck
```
